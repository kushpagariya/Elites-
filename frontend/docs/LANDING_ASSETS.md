## Native assets and component source

The expansion-pass front/back and strap are code-native SVG brand artwork. The Lanyard renderer is adapted from the complete React Bits source pasted by the user. Changes add top-down introduction framing, pause, context-loss/failure fallback, hidden-tab guards and capped pixel ratio. Three.js was already installed; no package or lockfile changed.

PillNav implements the requested pill API and fill/label-rollover interaction with native links and CSS, inspired by https://reactbits.dev/components/pill-nav. It uses actual landing anchors, a mobile disclosure with Escape/outside dismissal, active-section dots and visible keyboard focus. It needs no additional library.
